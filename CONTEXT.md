# Moyeora Dingding Mock Demo

A portfolio-oriented demo of the original team project. It exists so reviewers can evaluate the product experience without relying on the retired production backend.

## Language

**Portfolio mock demo**:
A reviewer-facing version of the project optimized for a stable demonstrable experience rather than full production feature parity.
_Avoid_: Production service, full production replica

**Core demo flow**:
An approved user journey that must remain usable without the retired production backend or optional external services.
_Avoid_: Every route, full feature set

**Optional demo feature**:
An approved feature outside the core demo flow whose supporting service may be unavailable without making the core demo unusable.
_Avoid_: Core flow
